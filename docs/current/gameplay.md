# Gameplay（現在の仕様）

> 根拠: `script.js` / `index.html`  
> 未実装の内容は書かない。将来案は [../roadmap/](../roadmap/) を参照。

## 概要

- **タイトル（HTML）:** CUBE PUZZLE
- **ジャンル:** 3D マッチングパズル（フレームワークなし）
- **目的:** 立方体上のブロックを同じ柄のペアで消し、**全ブロック消去**でクリア
- **敗北条件:** 制限時間切れ（Tutorial を除く）

## 難易度

| モード | `SIZE`（辺の長さ） | ブロック数 | 備考 |
|--------|-------------------|-----------|------|
| Tutorial | 2 | 8 | チュートリアル専用フロー（下記） |
| Normal | 4 | 64 | デフォルト（`localStorage` 未設定時） |
| Hard | 6 | 216 | 初クリアで Extra 解放 |
| Extra | 8 | 512 | `cube_extra_unlocked === "true"` のときタイトルに表示 |

Extra ボタンは解放前 `display: none`。Hard を**初めて**クリアしたとき `cube_extra_unlocked` が `"true"` に保存される。

## 盤面生成

1. 必要ブロック数 = `SIZE³`
2. ペア数 = ブロック数 / 2
3. `tileTypes` 配列（27種）を先頭から順に使い、各柄を2個ずつプールに追加（27種を超える場合は `%` で循環）
4. プールをシャッフルして `(x, y, z)` 順に配置
5. **内部ブロック**（6方向すべてに隣接ブロックがある位置）は `display: none` で非表示
6. 消去後、非表示だったブロックが **6方向のいずれかが空**（`isExposed`）になったら表示・面を生成

## ブロック選択

### 選択可能条件（`isSelectable`）

**左右・前後の4方向**（x±1, y±1）について、隣にアクティブなブロックがない方向を数え、**2方向以上が空**なら選択可。上下（z 方向）は選択判定に含めない。

### クリック時の挙動

| 状態 | 結果 |
|------|------|
| 未選択 | 1つ目として選択（黄色ハイライト） |
| 同じブロックを再クリック | 選択解除 |
| 同じ柄（`txt` 一致） | 2ブロック消去、+700 pt |
| 異なる柄 | エラー表示。2つ目として新ブロックを選択し直し |

ゲームオーバー・一時停止中はクリック無効。

### ステータスメッセージ（代表例）

- 通常: 「1つ目のブロックを選んでください」→「2つ目の同じ数字を選んでください」
- 不可: 「周囲に挟まれています（空きが1面以下なので選べません）」
- 不一致: 「数字が違います！」
- マッチ成功: 「消去成功！(+700pt)」

Tutorial では専用文言（例: 初回マッチ後「回転ボタンで視点を変えてみましょう」）。

## 回転

カメラ回転ではなく、**ブロック座標の入れ替え**。各ボタンは **180°** 回転（旧 90° から変更）。

操作パネルに **「180° ROTATE」** の説明表示あり。

| ボタン | id | 座標変換（180°） |
|--------|-----|------------------|
| ⇦ 左 | `rot-left-btn` | x,z を反転（X 軸まわり 180°） |
| ⇨ 右 | `rot-right-btn` | x,y を反転（Z 軸まわり 180°） |
| ⇧ 上 | `rot-up-btn` | x,y,z をすべて反転（中心対称） |
| ⇩ 下 | `rot-down-btn` | y,z を反転（Y 軸まわり 180°） |

表示上のステージ傾き: 初期 `rotateX(60deg) rotateZ(-45deg)`。ゲーム開始時にイントロアニメーションあり。

## タイマー

| モード | 初期値 | UI |
|--------|--------|-----|
| Tutorial | 999（カウントダウンなし） | 「チュートリアル」、バー 100% |
| Normal | 120 秒 | 「残り時間 N 秒」、バーは `timeLeft / 制限時間` |
| Hard | 170 秒 | 同上 |
| Extra | 200 秒 | 同上 |

1秒ごとに減算。PAUSE 中は停止。0 以下で TIME UP。

## スコア

### マッチ得点

- 1ペア消去: **+700 pt**（プレイ中の `currentScore` に加算）

### クリア時加算（Tutorial 除く）

```
finalScore = currentScore + clearBonus + timeBonus
timeBonus  = timeLeft × 2000
```

| モード | clearBonus |
|--------|------------|
| Normal | 20,000 |
| Hard | 75,600 |
| Extra | 200,000 |

クリア判定時に `finalScore` でハイスコア更新。プレイ中のリアルタイム BEST 更新はマッチ得点のみ（クリアボーナス前）。

### ランク（`getClearRankStars`）

| モード | 条件 | ランク |
|--------|------|--------|
| Tutorial | — | ★ |
| Normal | — | ★★（固定） |
| Hard | finalScore ≥ 151,200 | ★★★★ |
| Hard | finalScore ≥ 30,000 | ★★★ |
| Hard | それ以外 | ★★ |
| Extra | — | ★★★★★（固定） |

TIME UP 時も `currentScore`（クリアボーナスなし）でランク表示。

## Tutorial モードの差分

- タイトルの **Tutorial** ボタンから開始（LEVEL 選択とは独立）
- スコア / BEST 表示は `-`
- タイマー・ランク詳細・ボーナス内訳は結果画面で非表示または `★`
- クリアメッセージ: 「次はNORMALに挑戦！」
- クリアボーナス・タイムボーナスは 0

## クリア / TIME UP フロー

1. 残ブロック数 0 → クリア処理（効果音 `clear` → 500ms 後ファンファーレ）
2. Hard 初クリア → Extra 解放、`extraUnlockFanfare` 再生、結果画面に Extra 解放表示
3. 時間切れ → `timeup` 効果音、結果画面タイトル「TIME UP」、赤テーマ

結果画面から **CONTINUE**（再プレイ）/ **TITLE** / **SHARE** が可能。
